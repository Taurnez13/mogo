# antislop audit 001, 2026-11-10

Mode: after. Scope: every page in `app/templates/` and `app/static/app.css`, run locally and
clicked through (setup, login, titles, title detail with all six tabs, add title, contributors,
series, import, export, sync, settings). No console errors were seen. Nothing has been changed yet.

Priority follows rule tier: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Locks and
liveliness = LOW.

## Findings

1. **HIGH, R-02.** Em dashes in UI text: 40 occurrences across 14 templates plus one in a flash
   message in `web.py`. Most are the empty-value placeholder `—` in tables and fact lists; others
   are in help copy ("Thema codes: ...", "schema valid."). Replace with a comma or period in prose
   and with an empty cell, `none` or `not set` in data cells.

2. **HIGH, R-03.** Tables overflow on phones: `table.ledger` has no scrolling wrapper, so the
   titles, contributors and history tables push the page sideways below ~700 px.

3. **HIGH, R-03.** Tap targets under 44 px: `.btn` is about 34 px tall, `.btn.sm` about 26 px,
   the filter chips about 24 px, and the "remove" buttons in tables are `.btn.sm`.

4. **HIGH, R-25.** `--ink-3` (#7a858e) on the paper background measures 3.64:1, and 3.33:1 on the
   sidebar. It is used for `.muted`, `.sub`, `.help`, fact labels, tab counts and placeholders, all
   at 12 to 13.5 px, where AA requires 4.5:1. The amber status colour (4.28:1) also fails at 13 px.

5. **HIGH, R-27.** No loading state for long actions. "Download all remaining covers",
   "Generate ONIX 3.0", ONIX import, CSV import and the Cin7/Shopify pull and push can run for
   minutes with no feedback after the click; a second click starts a second job.

6. **HIGH, R-37 / R-31.** No `DESIGN.md`. The direction (serif book titles on a paper-white
   ledger, one oxblood accent, system fonts for intranet use, dials ENERGY 1 / RHYTHM 1 / MOTION 1)
   exists only in a chat message. Write it down so the choices are reviewable and contributors
   can follow them.

7. **HIGH, R-39.** `cursor: pointer` is set on `.btn` only; links, `<summary>`, `<select>`,
   checkbox labels and the filter chips inherit the default cursor. Disabled sync buttons have no
   `cursor: not-allowed` and no visually distinct disabled style.

8. **HIGH, R-39.** The cover-upload `<input type="file">` on the title page and the file inputs on
   the import page have no visible `<label>` (import has one; the title page does not). Heading
   levels skip: tabs on the title page go from `h1` straight to `h3` inside cards.

9. **HIGH, R-39.** Whole-document landmarks: there is `nav` and `main` but no `header` or
   `footer`; the brand block in the sidebar is a `<p>`.

10. **HIGH, R-40.** `<img>` elements (list thumbnails, cover on the title page) have no `width`
    and `height` attributes; sizing is CSS only.

11. **MEDIUM, R-06.** Typeface reason is not written down. The serif stack (Iowan Old Style /
    Palatino / Georgia) for book titles and the system sans for UI are deliberate (books are
    serif objects; no web-font dependency on an intranet) but undocumented. Fixed by finding 6.

12. **MEDIUM, R-09 / R-11.** Filter chips are pill-shaped while everything else uses a 3 px
    radius. They are functional toggles, so allowed, but the reason (pill = toggle, square =
    action) should be written down in `DESIGN.md`.

13. **LOW, liveliness ("Sterile Default").** Near-white background, thin grey rules, small
    radius, system fonts: the pattern antislop names as the over-filtered default. The identity
    present today is the serif title voice and the single oxblood accent. One repeated motif
    would anchor it; the strongest candidate already on the page is the brand mark's centred dot
    (`Taur·nez`), which could carry through as the separator in metadata lines (currently ` · `
    is used once in bylines) and the status dot in the ledger.

14. **LOW, R-24 / C-2.** The sidebar navigation renders on the login and setup pages, where every
    link redirects back to login. Hide the nav until signed in.

15. **LOW, R-27.** Empty states exist for titles, forthcoming, recent changes, exports and sync
    log, but not for the contributors list or the series list after a filter returns nothing.

16. **LOW, copy.** "Danger zone" (borrowed GitHub wording) and "Overview" are fine; "Feeds" and
    "System" as sidebar group labels are clear. Two labels are ambiguous: "Marked as exported
    (resets the delta)" and "Limit to formats" would read better as "Mark these records as sent"
    and "Only these formats".

## Not findings (checked, pass)

- R-15/R-16: no generic CTAs or buzzwords; actions are named ("Save changes", "Generate
  ONIX 3.0", "Download all remaining covers").
- R-17/R-18/R-36/R-38: every number on screen is live data from the database; no testimonials.
- R-26/R-35: every button posts to a route that exists; click-through recorded in the session.
- R-32: `:focus-visible` outline defined; no `outline: none`.
- R-29: ink, paper, one oxblood accent; green/amber/blue appear only as status semantics.
- R-01/R-07/R-10/R-12/R-13/R-19/R-22: no gradients, glow, blur, background grid, shadows,
  animation or stock illustration.
